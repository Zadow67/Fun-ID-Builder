# Fun ID Builder

Fun ID Builder lets you create custom ID cards inspired by movies. Upload your photo, place it on an ID, and download your own version.

## What can you make?

- **Loki TVA ID:** Create your own ID inspired by *Loki*.
- **McLovin ID:** Make a custom version of the iconic ID from *Superbad*.

## How to use it

1. Choose an ID design.
2. Upload your photo in PNG format.
3. Preview your ID.
4. Download your custom ID.

More ID designs will be added over time.

## Built with

HTML, CSS and JavaScript.

Made for fun and for learning web development.
